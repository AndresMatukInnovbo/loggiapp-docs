# Objetivo

Esta documentación describe el comportamiento **real** de cada integración implementada actualmente en el código fuente de LoggiApp.

Cada servicio documenta:

- Cuándo se ejecuta.
- Desde dónde se invoca.
- Qué información recibe.
- Qué información envía.
- Mapeo entre LoggiApp y el sistema externo.
- Flujo funcional.
- Request y Response.
- Consideraciones técnicas.
- Ubicación del código fuente.
